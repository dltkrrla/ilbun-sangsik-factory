# 1분 상식 — 영상 제작 기준 (v1, 2026-11-14)

## 1. 주제
- 한국 사람이 일상에서 "어? 왜지?" 하는 것 (소주병 색, 맥주병 색, 녹차·말차, 흰머리)
- 짝이 되는 주제를 이어서 (소주=마케팅 ↔ 맥주=과학), 지금 유행과 겹치면 가산점
- 건강 주제는 과장 금지: 증명 안 된 효과는 "아직 없다", 필요하면 "검사 받아 보세요"
- 이미 만든 주제(docs/EPISODES.md)는 다시 하지 않기

## 2. 사실 확인
- 대본의 모든 숫자·주장은 웹 출처 확인 후 사용, 출처를 docs/EPISODES.md에 기록
- 근거 약한 이야기는 빼기, 쥐 실험·소규모 연구는 "그런 사례가 있어요" 수준

## 3. 대본 (구연동화 말투)
- 9~10줄, 25~35초 (반전 있는 주제는 40초까지)
- ① **첫 문장은 인사·호칭 없이 단정·반전·손실형** ("소주병, 원래는 투명했어요." / "맥주를 햇빛에 30분 두면, 스컹크 냄새가 나요.") — "여러분," 으로 시작하지 않는다 (플레이북 H1·H2)
- ② 3초 안에 첫 답(보상) (H4)
- 중간: 자문자답("왜냐고요?"), 끊어 읽기("~요,"), 감탄사("무려", "싹", "딱", "으,")
- 끝 전: 써먹는 한마디 ("다음 술자리에서 슬쩍 얘기해 보세요. 박수 받으실걸요?")
- 마지막: "알고 있었다면, 댓글로 알려 주세요!"
- SPOKEN(읽기용)은 숫자를 한글로 풀어 씀 (천구백구십사 년), 자막은 숫자로

## 4. 목소리
- Supertonic 3 남성 sid=5, 문장마다 4번 생성 → 음성 인식 정확도 + 억양으로 선택
- 감정: curious · surprised · excited · amazed · sad · disgust · secret · bright · explain
- 느린 속도는 생성 속도로만 (소리 늘리기 금지), 음높이 튐 보정 — emote.py/natural_vo.py에 구현됨
- make.py의 ASR_LOW_LINES에 나온 줄은 문장을 바꾸거나 다시 생성

## 5. 화면
- 1080×1920 30fps, 남색 배경 + 노랑 강조 + 흰 글자, 상단 시그니처만 (**고정 제목 줄 없음** — 답을 먼저 알려줘서 훅을 망침, 2026-11-14 사용자 결정. T는 업로드 제목용으로만 씀)
- 0초부터 중앙에 큰 글자 훅 (vtl.build의 Q) — 말하는 첫 문장과 같은 약속 (H6)
- 첫 프레임부터 움직임 + 답의 단서 (확대·튀어나옴·빨간 표시) (H3)
- 1.5~2초마다 화면 변화: 한 문장 안에서도 확대·글자 교체·튀어나옴을 넣는다 (H5)
- 이모지 + 직접 그린 일러스트, 실존 인물·브랜드 로고·캐릭터 금지
- 자막 2줄 핵심어 노랑, 끝 "구독하면 매일 1분 상식"
- 안전 영역: 아래 약 580px, 오른쪽 약 170px에 글자·핵심 그림 금지 (패널 fit 0.82가 이미 맞춰 줌)
